# 设备发现与纳管

## 页面与 DOM 取证

使用项目自身已认证的 Playwright 会话，先读取当前页面真实 DOM，再编写每一个非简单定位器。不得根据截图、其它页面、旧录制脚本或固定行号推测选择器。

涉及普通表单字段时，按“定位字段容器 → 填写 → `Tab` 失焦 → 断言值保留”处理；涉及下拉层时，仅在当前可见弹层内选择。

## 通用流程

1. 打开用户指定的发现页面，确认操作系统、协议或设备类别控制项实际存在。
2. 在唯一且可编辑的 IP 输入控件中填写用户指定 IP；多行输入保持完整值。
3. 启动发现后，对每个目标 IP 等待其离开“扫描中”等中间状态。使用状态断言，不使用固定等待。
4. 根据真实结果行和用户指定 IP 勾选设备；断言“添加监控”等下一步按钮可用后再点击。
5. 页面状态切换后重新检查 DOM。用稳定的业务键（通常为 IP 或设备名）重新定位，不复用发现页的行、行 ID 或复选框。
6. 在真实可见表单中按字段标签填写补充信息并保存；确认表单关闭或保存状态已出现后，再处理下一台设备。
7. 断言“添加纳管”或等效操作可用后点击；确认弹窗只在当前可见确认容器中处理。

## 定位与验证

- 不要对 IP 行、重复动作按钮或表单字段使用 `.nth()`。
- 每次点击前确认目标唯一且可用；保存或状态切换后重新查询。
- VXE 表头的全选控件可能是原生 `input` 或 `span`。先检查真实结构，不能假定固定选择器。
- 发现超时默认 30 秒；用户明确要求时再调整。

## 失败处理

- 找不到预期结果、弹层或字段时，停止并重新检查当前状态的 DOM，不猜测替代定位器。
- 设备已监控或已纳管时视为幂等结果；不要强制重复点击。
- 目标设备已勾选但下一步按钮仍不可用时，检查当前结果状态与选择控件，不伪造表头全选定位器。
